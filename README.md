Padrão de Organização dos Módulos

Todos os módulos devem seguir a estrutura:

02_MODULOS/

└── MXX_NOME_MODULO/

    └── MK_ESPECIFICACAO_MODULO_NOME.md

Padrão:

MXX representa o número do módulo;
NOME_MODULO representa a identificação do módulo;
MK_ESPECIFICACAO_MODULO_NOME.md representa o documento oficial de especificação.
